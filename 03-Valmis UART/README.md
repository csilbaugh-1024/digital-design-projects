# Valmis UART

## Project goal
The goal of this project is to design a UART from scratch in stages to gain experience with hardware communication and FPGA design. Because this design will evolve as I complete it in steps, I have decided to give it a name: Valmis. Stage 1, called Valmis Mk. 1, will only have transmitter capabilities. When the design advances to Valmis Mk. 2, it will gain receiver capabilities. Next, Valmis Mk. 3 will be able to echo back words that are sent to it. Valmis Mk. 4 will include CLI capabilties.
