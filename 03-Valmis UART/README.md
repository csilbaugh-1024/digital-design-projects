# Valmis UART

## Project goal
The goal of this project is to design a UART from scratch in stages to gain experience with hardware communication and FPGA design. Because this design will evolve as I complete it in steps, I have decided to give it a name. I chose "Valmis", which is the word for "Ready" in my favorite language I speak, Finnish. Stage 1, called Valmis Mk. 1, will feature only a transmitter. Next, Valmis Mk. 2 will be a receiver. Finally, Valmis Mk. 3 will combine the functionality of Mk. 1 and Mk. 2 and feature full transmitter/receiver functionality.
